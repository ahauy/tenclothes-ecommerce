## **DỰ ÁN**
**10/2025 - Hiện nay** | **Dự án phần mềm ứng dụng trong hệ thống bán quần áo**

**Vị trí: Full-stack Developer**

- **Link Github:** [https://github.com/ahauy/tenclothes-ecommerce](https://github.com/ahauy/tenclothes-ecommerce)
- **Demo:** [https://tenclothes-ecommerce-fontend.vercel.app](https://tenclothes-ecommerce-fontend.vercel.app)
- **Số lượng thành viên:** 1
- **Mô tả sản phẩm:** Dự án ứng dụng web thương mại điện tử theo kiến trúc tách biệt RESTful API, tập trung vào tối ưu trải nghiệm người dùng và tính an toàn của dữ liệu.
- **Công nghệ sử dụng:**
    - **Frontend:** React.js (TypeScript), Vite, Tailwind CSS, Zustand, SWR, React Hook Form
    - **Backend:** Node.js, Express.js (TypeScript)
    - **Database & Storage:** MongoDB (Mongoose), Cloudinary
    - **Công cụ & Thư viện:** Multer, bcrypt.
    - **Xác thực & Validate:** JWT, Zod
    - **Kiến trúc:** RESTful API, 3-layer Architecture
- **Vai trò:**
    - Thiết kế và triển khai toàn bộ Database Schema bằng MongoDB & Mongoose.
    - Xây dựng hệ thống RESTful API an toàn với JWT (Access/Refresh Token) và Zod Validation.
    - Phát triển giao diện người dùng (Client) và bảng quản trị (Admin) chuyên sâu với React + Tailwind CSS.
    - Tích hợp Cloudinary để quản lý hình ảnh sản phẩm.
    - Tối ưu hóa hiệu suất ứng dụng và trải nghiệm người dùng (UX) theo phong cách "Quiet Luxury".
